# CoffeeBar

☕ Keep your Mac awake while your work is running.

CoffeeBar is a lightweight native macOS menu bar application that prevents idle system sleep using Apple's native APIs.

Unlike shell wrappers, CoffeeBar integrates directly with macOS and provides a simple menu bar interface.

## Features

- Native macOS
- Menu Bar only; no main window or permanent Dock icon
- Manual Keep Mac Awake toggle
- Prevents idle system sleep without preventing display sleep
- Lightweight
- SwiftUI

## Usage

1. Launch CoffeeBar.
2. Open the cup icon in the menu bar.
3. Enable **Keep Mac Awake** while work is running.
4. Disable it to return idle sleep management to macOS.

CoffeeBar always starts inactive and does not change macOS power settings permanently.
